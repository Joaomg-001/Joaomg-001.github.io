Horror Game Prototype

A playable horror prototype in Unreal Engine 5, expanded with my own gameplay systems.

Unreal Engine 5BlueprintsNavMesh
More details

It started from Zenva's Make a Horror Game in Unreal Engine course, which I then expanded with my own systems:

  • Enemy AI: improved the course's AI and gave the enemy several distinct behaviours.
  • Player movement & health: increased player health so they can survive multiple hits, and added an omni-directional dash.
  • Radar: a fully functional radar that targets items, built from scratch.
  • Inventory: a simple inventory that tracks the items the player has picked up.
  • Item spawning: items appear at random among a set of defined spawn points, so each run is different.
  • Menus: a start menu, level select and an options screen.
