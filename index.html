Overview

A fully functional horror prototype built in Unreal Engine 5 with Blueprints, featuring NavMesh AI navigation and dynamic lighting.

It started from Zenva's Make a Horror Game in Unreal Engine course, which I then expanded with my own systems.

What I added

  • Enemy AI: Improved the course's AI and gave the enemy several distinct behaviours.
  • Player Movement and Health: Player life was increased to take multiple hits, and omni-directional dash was added.
  • Radar: Fully functional radar that targets items.
  • Inventory: A simple inventory that tracks the items the player has picked up.
  • Item Spawning: Items appear at random among a set of defined spawn points, so each run is different.
  • Main menu & options: A start menu, Level select and an options screen. (There is a bug with the volume slider)
